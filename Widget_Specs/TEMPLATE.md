Create a widget that displays the current weather in London, UK.

Requirements:
- Use the Open-Meteo API (https://api.open-meteo.com/v1/forecast?latitude=51.5074&longitude=-0.1278&current=temperature_2m)
- Show temperature, weather icon, and description
- Allow user to toggle between Celsius and Fahrenheit display in CMS Dashboard
- Follow the folder-based widget structure (see [widgets/README.md](../widgets/README.md) and [Documentation/WidgetDevelopmentGuideV2.md](../Documentation/WidgetDevelopmentGuideV2.md))

Use the current Widget Development Guide V2 and widgets/README as reference.
